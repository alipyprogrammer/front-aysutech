# Aysutech Website

وب‌سایت معرفی فارسی و راست‌چین آیسو تک با Next.js، TypeScript و Tailwind CSS.

## اجرا

```bash
pnpm install
pnpm dev
```

## ساخت نسخه نهایی

```bash
pnpm build
pnpm start
```

## ویرایش اطلاعات تماس

ایمیل و شماره نمونه در فایل `app/page.tsx` هستند. پیش از انتشار این موارد را تغییر دهید:

- `hello@aysutech.ir`
- `۰۹۱۲ ۰۰۰ ۰۰۰۰`
- `+989120000000`

## فایل‌های اصلی

- `app/page.tsx`: محتوای صفحه
- `app/globals.css`: طراحی و حالت واکنش‌گرا
- `app/layout.tsx`: اطلاعات سئو و تنظیمات زبان
- `public/favicon.svg`: آیکن سایت
